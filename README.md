## How to run

### Option 1: Google Colab (recommended, no install)
Click the "Open in Colab" badge next to any notebook above — it runs in your browser,
nothing to install.

### Option 2: local clone
```bash
git clone https://github.com/hankpark0706/OL7014-integer-programming.git
cd OL7014-integer-programming
pip install -r requirements.txt
```
Running the models needs a Gurobi license. Students can request a free
[academic license](https://www.gurobi.com/academia/academic-program-and-licenses/).
